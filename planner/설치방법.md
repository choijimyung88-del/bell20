# 데일리 플래너 · 알도큐브 iPlay 60 mini Pro 설치하기

## 1단계 · 인터넷 주소로 올리기 (한 번만)
이 저장소를 GitHub Pages로 켜 두면 아래 주소로 열 수 있어요.
1. GitHub 저장소 → **Settings → Pages** → Branch를 `main` / `root`로 저장합니다.
2. 1~2분 뒤 `https://아이디.github.io/bell20/planner/` 주소가 생깁니다.

(또는 https://app.netlify.com/drop 에 `planner` 폴더를 끌어다 놓아도 돼요.)

## 2단계 · 태블릿 홈 화면에 앱으로 설치
1. 태블릿 **Chrome**으로 위 주소를 엽니다.
2. 오른쪽 위 **⋮ 메뉴 → 홈 화면에 추가(또는 앱 설치)** → **설치**.
3. 홈 화면의 플래너 아이콘으로 열면 주소창 없이 전체 화면으로 실행되고, 인터넷이 없어도 돌아가요.

## 펜 사용
- **일반 터치펜(고무·디스크 팁)**: 그대로 쓰면 돼요. 손바닥이 넓게 닿으면 무시하지만, 쓸 때 손을 살짝 띄우면 가장 깔끔해요.
- **액티브 펜(전자펜)**: 펜이 감지되면 자동으로 *펜 전용*으로 바뀌어 손바닥·손가락은 그려지지 않아요. 필압에 따라 굵기가 달라지고, 펜의 지우개 버튼으로 지울 수 있어요.
- 입력 방식은 오른쪽 위 **⋯ → 입력 방식**에서 직접 바꿀 수 있어요.

## 참고
- 기록은 태블릿 Chrome 안에 저장돼요. **⋯ → 백업 파일 저장**으로 가끔 백업해 두세요.
- 화면은 세로 방향에 맞춰져 있어요.
